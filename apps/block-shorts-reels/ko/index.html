개인정보처리방침 — 쇼츠·릴스 차단

시행일: 2026년 8월 2일

쇼츠·릴스 차단(이하 "앱")은 사용자의 개인정보를 존중합니다. 본 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다. 요약하면, 앱은 사용자를 식별하는 개인정보를 수집·저장·전송하지 않습니다. 화면 차단에 필요한 정보는 전부 기기 안에서 실시간으로만 처리됩니다.

1. 앱이 접근하는 정보와 사용 목적

화면 감지 (접근성 서비스)

앱은 유튜브 쇼츠, 인스타그램 릴스, 틱톡, 네이버 클립, 카카오톡 숏폼 같은 숏폼 영상 화면을 감지하기 위해 안드로이드 접근성 서비스를 사용합니다. 이를 위해 현재 화면의 앱 종류와 화면 구성 요소를 읽습니다.

  • 이 정보는 오직 기기 안에서 실시간으로 "지금 화면이 차단 대상인가"를 판단하는 데만 사용됩니다.
  • 저장하거나, 기록하거나, 외부 서버로 전송하지 않습니다. 판단이 끝나면 즉시 폐기됩니다.
  • 앱은 사용자가 입력하는 내용, 비밀번호, 메시지, 개인 콘텐츠를 수집하지 않습니다.

설치된 앱 목록 (앱 전체 차단 기능)

"앱 전체 차단" 기능은 사용자가 직접 고른 앱을 통째로 차단합니다. 선택 화면에 후보를 보여주기 위해 기기에 설치된 앱 중 홈 화면에 아이콘이 있는 앱의 이름과 아이콘을 읽습니다.

  • 이 목록은 선택 화면을 그리는 데만 쓰이며, 저장하거나 외부로 전송하지 않습니다.
  • 사용자가 차단 대상으로 직접 고른 앱의 패키지명만 설정값으로 기기 안에 저장됩니다.
  • 앱은 QUERY_ALL_PACKAGES 권한을 사용하지 않습니다. 설치된 앱 전체가 아니라, 실행 아이콘이 있는 앱으로 조회 범위를 좁혀 필요한 최소한만 확인합니다.

앱 설정 (기기 내 저장)

플랫폼별·앱별 차단 ON/OFF, 차단 대상으로 고른 앱 목록, 오늘 차단 횟수, "5분 허용" 만료 시각 등 설정값은 기기 내부 저장소에만 저장되며 외부로 전송되지 않습니다. 앱을 삭제하면 함께 삭제됩니다.

광고 (Google AdMob)

앱은 차단 해제 "5분 허용" 등에 Google AdMob 리워드 광고를 사용합니다. 광고 제공을 위해 Google 및 그 파트너가 광고 식별자(Advertising ID), IP 주소, 기기·사용 정보 등을 수집·처리할 수 있습니다. 이는 Google의 정책을 따릅니다.

  • Google 개인정보처리방침: https://policies.google.com/privacy
  • 광고 관련 안내: https://support.google.com/admob/answer/6128543

앱 개발자는 광고를 통해 사용자의 개인정보를 별도로 수집하지 않습니다.

2. 계정·회원가입

앱은 회원가입이나 로그인이 없으며, 이름·이메일·전화번호 등 개인정보를 요구하지 않습니다.

3. 사용 권한

앱이 직접 선언한 권한

권한사용 목적
접근성 서비스숏폼 화면을 감지해 차단 화면을 띄우기 위함
다른 앱 위에 표시차단 화면(오버레이)을 표시하기 위함
기기 부팅 시 실행재부팅 후에도 차단이 계속 작동하도록
인터넷 / 네트워크 상태광고를 불러오기 위함

광고 SDK(Google AdMob)가 자동으로 추가하는 권한

앱이 직접 요청하지는 않지만, 광고 SDK를 포함하면 함께 설치 패키지에 들어가는 권한입니다.

권한사용 목적
광고 ID 접근 (ACCESS_ADSERVICES_AD_ID)광고 게재·빈도 제한
광고 기여도 측정 (ACCESS_ADSERVICES_ATTRIBUTION)광고 성과 측정
광고 주제 (ACCESS_ADSERVICES_TOPICS)관심사 기반 광고
절전 모드 해제 (WAKE_LOCK)광고 SDK 내부 작업 처리
포그라운드 서비스 (FOREGROUND_SERVICE)광고 SDK 내부 작업 처리

이 권한들로 처리되는 데이터는 위 "광고(Google AdMob)" 항목의 설명과 Google 정책을 따릅니다.

사용하지 않는 권한

권한설명
설치된 앱 전체 조회 (QUERY_ALL_PACKAGES)사용하지 않습니다. "앱 전체 차단"의 앱 선택 목록은 매니페스트 <queries>에 선언한 범위(홈 화면에 아이콘이 있는 앱)만 조회합니다.

4. 아동 개인정보

앱은 아동을 주 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

5. 제3자 제공

앱 개발자는 사용자의 개인정보를 제3자에게 판매·제공하지 않습니다. 광고 제공에 관한 데이터 처리는 위 Google AdMob 항목을 따릅니다.

6. 이용자의 권리

앱은 개인정보를 서버에 수집·저장하지 않으므로 서버에서 열람·정정·삭제할 데이터 자체가 없습니다 — 모든 앱 데이터는 기기 안에만 있으며 앱 삭제 시 함께 삭제됩니다. 광고 식별자 재설정·맞춤 광고 해제는 기기의 Android 설정(설정 → Google → 광고)에서 언제든 할 수 있습니다. 개인정보 권리(GDPR·CCPA 포함)에 관한 문의는 아래 연락처로 주십시오.

7. 방침 변경

본 방침은 필요 시 개정될 수 있으며, 개정 시 앱 또는 본 페이지를 통해 공지합니다.
